    Why you can trust it

    👁

    Vision observes, rules decide

    The vision step can only describe what it sees. A rule engine makes every decision and cites the Amazon rule — text printed on a package can't talk it into a pass.

    🤔

    Honest “needs review”

    Blur, glare or a missing view? It says so instead of guessing, and asks for a better photo — without paying for a model call.

    📋

    Work order is not proof

    It checks what Amazon requires for the category, even when the work order forgot it — and flags the gap.

    🔏

    Evidence that holds up

    Every result is sealed with SHA-256 and stored once. Overrides need a reason and never erase the original.

    🏢

    Each prep center isolated

    The API key decides whose data you see. Images use short-lived signed links. An audit proves zero cross-tenant rows.

    ⚡

    Never stops the line

    If the model is slow or down, the unit goes to review in bounded time with the photo kept.

    Override this check

    Signed with the identity of the selected key. Operators may only make a result stricter; turning a Fail or Needs-review into a Pass needs the supervisor key.
